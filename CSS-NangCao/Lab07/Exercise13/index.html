Setting the Viewport

Dùng viewport thiết bị và đổi kiểu điều hướng.

Bài này tiếp tục trên HTML và hai stylesheet của 7.12. width=device-width đặt chiều rộng layout viewport theo thiết bị. CSS hiển thị danh sách ul trên desktop và ô chọn select trên mobile.

Mở demo riêng ở chế độ giả lập điện thoại rồi đổi giữa 480px và 481px để thấy điều khiển điều hướng thay đổi.
