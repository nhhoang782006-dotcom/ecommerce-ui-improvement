Thông điệp với noscript

Thẻ <noscript> cho phép trang giải thích điều gì đang xảy ra nếu trình duyệt tắt JavaScript hoặc không hỗ trợ script.

THÔNG BÁO TRẠNG THÁI

Trạng thái hỗ trợ

Đang kiểm tra khả năng chạy JavaScript…

Để kiểm tra thông báo dự phòng, hãy tắt JavaScript bằng cài đặt hoặc tiện ích của trình duyệt rồi tải lại trang. Thẻ noscript được xử lý bởi trình duyệt; JavaScript không thể tự tắt chính nó để mô phỏng trạng thái này.

Vì sao cần dự phòng?

Thông báo dự phòng làm rõ giới hạn tính năng cho người đọc. Hãy giữ thông tin quan trọng ở HTML thay vì chỉ tạo nó bằng JavaScript.
