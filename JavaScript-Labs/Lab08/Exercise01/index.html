BÀI 8.1 · TRẠNG THÁI TRÌNH DUYỆT

Bật và tắt JavaScript

Trang web có thể phản ứng khi JavaScript được bật. Khi tắt JavaScript trong trình duyệt, nội dung HTML vẫn còn và phần hướng dẫn dự phòng sẽ xuất hiện.

JavaScript đang hoạt động?

Đang chờ script chạy…

Thử hai trạng thái

  1. Trạng thái bật: tải lại trang và đọc trạng thái phía trên.
  2. Trạng thái tắt: mở cài đặt JavaScript của trình duyệt, chặn script cho trang này rồi tải lại. Bật lại cài đặt và tải lại để xem trạng thái ban đầu. Trên Edge, trang cài đặt là edge://settings/content/javascript; tên mục có thể khác ở trình duyệt khác.

Điều cần nhớ

HTML cung cấp nội dung nền. JavaScript bổ sung hành vi; thẻ <noscript> cung cấp lời nhắn khi script không chạy.
