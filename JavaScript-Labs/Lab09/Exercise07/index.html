Đổi màu khi focus và blur

Theo dõi focus và blur trên ô văn bản cùng ô mật khẩu; nền vàng báo đang nhập, nền trắng báo đã rời ô.

FOCUS · BLUR · STYLE

Quan sát trạng thái

Nhấn Tab hoặc chọn một ô để bắt đầu.

Sự kiện focus và blur dùng được cho cả thao tác chuột lẫn bàn phím.

Đọc mã nguồnVí dụ ngắn, có chú thích 
for (const field of fields) {
  field.addEventListener("focus", () => {
    field.style.backgroundColor = "#fff2a8";
  });
  field.addEventListener("blur", () => {
    field.style.backgroundColor = "#ffffff";
  });
}
