Cây bên phải có xuống dòng, thụt lề và một ghi chú HTML. Chọn nút để liệt kê các nút con theo đúng thứ tự.

Kết quả sẽ xuất hiện ở đây.
  • Mục thứ nhất
  • Mục thứ hai
Đọc mã nguồnVí dụ ngắn, có chú thích 
const list = root.querySelector("#node-list");
const first = list.firstChild; // thường là nút văn bản do xuống dòng

for (const node of list.childNodes) {
  if (node.nodeType !== Node.TEXT_NODE) {
    console.log("Nút không phải văn bản:", node.nodeName);
  }
}
console.log(first.nextSibling.parentNode === list);
