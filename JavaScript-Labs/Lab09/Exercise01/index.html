Thẻ được truy vấn

Một ghi chú nhỏ

Các selector cùng trỏ đến phần tử trong phạm vi ví dụ này.

Lớp có thể được bật hoặc tắt bằng classList.

Chọn “Đọc các bộ chọn” để xem kết quả; thử nhập ghi chú rồi chọn “Cập nhật nội dung”.
Đọc mã nguồnVí dụ ngắn, có chú thích 
const root = document.querySelector("#demo-9-1");
const card = root.querySelector("#selector-card");
const paragraphs = card.getElementsByTagName("p");
const copies = card.getElementsByClassName("card-copy");
const firstCopy = card.querySelector(".card-copy");
const allCopies = card.querySelectorAll(".card-copy");

card.setAttribute("title", "Đã được cập nhật");
card.classList.toggle("is-highlighted");
card.style.borderColor = "#368c78";
firstCopy.innerHTML = "<strong>Nội dung</strong> được thay đổi";
output.innerText = textarea.value;
