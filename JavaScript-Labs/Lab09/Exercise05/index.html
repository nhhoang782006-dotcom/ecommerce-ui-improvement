Phòng thực hành

SCRIPT ORDER · NULL · WINDOW LOAD

Một script ở đầu trang lưu kết quả truy vấn khi phần tử chưa được trình duyệt tạo. Chọn nút để tái hiện thao tác lỗi; trang vẫn hoạt động bình thường.

Đang chờ sự kiện load để áp dụng cách sửa.

Phần tử trong DOM

Nội dung chờ DOM

Khi trang tải xong, listener sẽ tìm phần tử rồi cập nhật dòng tiêu đề.

Đọc mã nguồnVí dụ ngắn, có chú thích 
// Cách lỗi: script chạy trước thẻ có id="message".
const message = document.querySelector("#message");
message.innerText = "Xin chào"; // message đang là null

// Cách sửa: truy vấn khi tài liệu đã tải xong.
window.addEventListener("load", () => {
  const readyMessage = document.querySelector("#message");
  readyMessage.innerText = "DOM đã sẵn sàng";
});
