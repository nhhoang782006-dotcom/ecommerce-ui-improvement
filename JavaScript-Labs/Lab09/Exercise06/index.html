THỬ NGAY TRÊN TRANG

Phòng thực hành

DEVTOOLS · DEBUGGER · EVENT TARGET

Mở DevTools trước khi bật điểm dừng. Rê chuột qua từng thẻ để xem e.target.id và thử Step over / Watch.

Chưa có vùng nào được chọn.
Đọc mã nguồnVí dụ ngắn, có chú thích 
grid.addEventListener("mouseover", (e) => {
  const box = e.target.closest("[data-inspect-box]");
  if (!box) return;
  const id = e.target.id; // thêm biến này vào Watch
  if (breakpoint.checked) debugger;
  output.textContent = `e.target.id = ${id}`;
});
