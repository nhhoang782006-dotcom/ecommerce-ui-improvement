Phòng thực hành

CLICK · MOUSEOVER · MOUSEOUT · SET TIMEOUT

Rê chuột lên ảnh để chuyển sang thang xám. Dùng nút bên dưới để xem đoạn văn ẩn/hiện.

Sẵn sàng nhận sự kiện.

Đoạn văn này chuyển động nhẹ khi bạn ẩn hoặc hiện nội dung.

Đọc mã nguồnVí dụ ngắn, có chú thích 
button.addEventListener("click", () => count++);
image.addEventListener("mouseover", () => image.style.filter = "grayscale(1)");
image.addEventListener("mouseout", () => image.style.filter = "grayscale(0)");

paragraph.classList.add("is-hiding");
setTimeout(() => paragraph.hidden = true, 300);
