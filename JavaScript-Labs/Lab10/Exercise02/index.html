Đổi nhãn mẫu

Nhập tên sách rồi áp dụng. Giá trị được đọc bằng val(); khung mẫu dùng html(), attr(), css() và addClass().

Gợi ý đọc

Một cuốn sách nhỏ cho buổi tối

Chọn một tựa sách để cập nhật tấm thẻ này.

Xem thẻ

Mã nguồn minh họa

Ý chính của bài

const name = $("#book-name").val();
$("#book-title").html($("").text(name).html());
$("#book-link").attr("title", "Thẻ gợi ý: " + name);
$("#book-card").css("border-color", "#60a99a").addClass("is-highlighted");

Đọc input bằng val, cập nhật html, đổi attr và css, sau đó thêm class để thể hiện trạng thái.
