Danh sách thành phố Việt Nam

Bản này đổi nguồn API so với bài gốc sang CountriesNow qua HTTPS để chạy trên GitHub Pages; trang không gọi endpoint cũ qua HTTPS. Phản hồi API là mảng chuỗi, được đổi thành đối tượng { name } trước khi hiển thị.

Nguồn dữ liệu: countriesnow.space/api/v0.1/countries/cities/q. Không có dữ liệu mẫu dự phòng; lỗi mạng/API sẽ được báo trực tiếp. Yêu cầu bị treo sẽ kết thúc sau 15 giây.

Quốc gia: Việt Nam

Nhấn tải danh sách để gọi API.

    Mã nguồn minh họa

    Ý chính của bài

    $.get(API_URL, { country: "Vietnam" }, null, "json")
  .done(function (response) {
    const cities = response.data.map(function (name) {
      return { name: name };
    });
    renderCities(cities);
  })
  .fail(showRequestError);

    Gửi GET đến API HTTPS, xác nhận phản hồi và đổi chuỗi thành đối tượng {name}.
